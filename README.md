# JN60101 Japanese for Communication 1 (ภาษาญี่ปุ่นเพื่อการสื่อสาร 1)

คลังสรุปเนื้อหา แบบฝึกหัด และงานที่ได้รับมอบหมายของรายวิชา **JN60101 ภาษาญี่ปุ่นเพื่อการสื่อสาร 1 (Japanese for Communication 1)**
สถาบันการจัดการปัญญาภิวัฒน์ (PIM) — ภาคการศึกษา 1/2569 — กลุ่มเรียน 1.2-1

---

## 📌 ข้อมูลรายวิชาเบื้องต้น

- **อาจารย์ผู้สอน:** อาจารย์ ดร.เอกนรินทร์ จิรชีวีวงศ์ (กลุ่มวิชาภาษาเพื่อการสื่อสาร สำนักการศึกษาทั่วไป)
- **รูปแบบการเรียน:** Onsite 100%
- **ช่องทางหลัก:** LINE กลุ่ม (ติดต่อสื่อสาร) + PIM e-Learning (ส่งงานทุกชิ้น)
- **ช่วงเวลา:** 9 กันยายน 2569 – 11 พฤศจิกายน 2569 (10 สัปดาห์)
- **วัตถุประสงค์ของวิชา:** 1) ฟังภาษาญี่ปุ่นเบื้องต้นออก 2) สื่อสารภาษาญี่ปุ่นพื้นฐานได้ 3) มีความสุขในการเรียน
