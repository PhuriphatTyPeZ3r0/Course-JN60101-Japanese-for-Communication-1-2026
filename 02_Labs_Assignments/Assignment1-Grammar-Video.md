## <span class="material-symbols-outlined">assignment</span> รายละเอียดงาน

- อัดคลิปวิดีโอเดี่ยว อธิบายการใช้ไวยากรณ์ 1 หัวข้อ — **ต้องเห็นหน้าผู้พูดระหว่างอัดคลิปด้วย**
- จับหัวข้อไวยากรณ์ที่ต้องอธิบายใน **สัปดาห์ที่ 3 ของการเรียน** (พุธ 23 กย 2569)
- คะแนนเต็ม **10 คะแนน** (จาก 25 คะแนนของ "งานที่ได้รับมอบหมาย")

## <span class="material-symbols-outlined">ads_click</span> หัวข้อไวยากรณ์ที่อาจถูกจับได้ (ประเด็นในการอธิบาย)

1. `__wa__desu` / `__wa__desuka?` / `__wa__dewa arimasen` — คำช่วย wa / คำช่วย ka / haii / iie / การละ Noun 1 wa
2. คำช่วย mo / คำช่วย no / kore, sore, are / kono, sono, ano
3. `Sō desu` / `Sō desu ka?` / `Sō dewa arimasen` / koko, soko, asoko / kochira, sochira, achira
4. การบอกเวลา (โมง นาที) / การบอกวัน วันที่ เดือน ปี / คำช่วย `...kara ...made`
5. จำนวนและตัวเลข (ถึง 1,000,000) ข้อควรระวังในเลขแต่ละหลัก การอ่านทศนิยมและเศษส่วน
6. การถามราคา ลักษณนาม การใช้คำคุณศัพท์กับคำนาม
7. คำบอกเวลา (วัน สัปดาห์ เดือน ปี .. นี้ / ที่แล้ว / หน้า) การผันคำกริยา (บอกเล่า ปฏิเสธ ปัจจุบัน อดีต)
